## 📖 About the Project

AgriSynth is a smart agriculture and livestock management 
platform developed as a Computer Engineering graduation project.

This repository contains the mobile application of the 
AgriSynth ecosystem, designed to help farmers manage their 
daily agricultural activities, access veterinary services, 
communicate with other users, and participate in a digital 
agricultural marketplace.

The application integrates with a centralized backend, 
enabling data synchronization between web and mobile platforms.

## 🚀 Key Features

- Secure user authentication and profile management
- Agricultural activity and farmland management
- Digital marketplace for agricultural products and livestock
- Product listing creation and management
- User-to-user messaging
- Online veterinary appointment management
- Personal notes, calendar and reminders
- Real-time data synchronization

backend, providing shared data management and synchronization 
with the AgriSynth web platform.

## ⚙️ Installation

1. Clone the repository:

   git clone https://github.com/boraemir/AgriSynth_Farmer_App.git

2. Navigate to the project directory:

   cd AgriSynth_Farmer_App

3. Install dependencies:

   flutter pub get

4. Configure the required Supabase connection settings.

5. Run the application:

   flutter run
